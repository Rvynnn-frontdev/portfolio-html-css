# Portfolio — HTML & CSS Practice

This repository contains a simple portfolio website created **for practice purposes**.

The project focuses on building and improving frontend development skills using only:

- HTML
- CSS

The portfolio is intended as a practice project to explore webpage structure, styling, layout, responsiveness, and basic UI design.

## Purpose

This project was created to practice:

- Semantic HTML structure
- CSS styling and layouts
- Responsive web design
- Portfolio website structure
- Frontend development fundamentals

## Technologies Used

- HTML5
- CSS3

## Note

This is a **practice project** and is not intended to represent a final or production-ready portfolio.

More projects and technologies will be added as I continue developing my frontend development skills.
